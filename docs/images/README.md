# README product image

`codeboarding-review.png` is a screenshot of the live [web platform reviewing public PR #586](https://app.codeboarding.org/CodeBoarding/CodeBoarding/pull/586), captured on 2026-09-19 without signing in. It contains only public CodeBoarding repository data.

To reproduce: use the light theme at a 1280 × 800 viewport with 2× pixel density, dismiss the tour, collapse the left review panel, and widen the docked code panel. Expand **Static Analysis Engine** and use **Focus component** to show its four subcomponents beside the unified diff. Move the pointer off the map before capturing.

The PNG is 2560 × 1600 pixels, losslessly optimized with metadata removed (about 415 KiB). No product content was edited. A static image keeps labels available without animation; click through from the README to explore the live example. No GIF is needed for this side-by-side view.
